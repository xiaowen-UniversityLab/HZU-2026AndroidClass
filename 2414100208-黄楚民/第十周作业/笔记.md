### 主要缩减来源
- 去掉了 `findViewById` 的类型转换和变量声明
- Lambda 替代匿名内部类（`setOnClickListener { ... }`）
- 空安全操作符替代 null 检查 if 语句
- `companion object` 替代 `private static final`
- 类型推断减少显式类型声明
