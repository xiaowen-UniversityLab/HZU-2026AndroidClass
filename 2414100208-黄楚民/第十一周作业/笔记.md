# 第十一周学习笔记 — Kotlin 协程（Coroutines）

## 核心知识点

### 1. 协程作用域（Scope）
viewModelScope`：绑定 ViewModel 生命周期，ViewModel 销毁时自动取消
lifecycleScope`：绑定 Activity/Fragment 生命周期
GlobalScope`：全局作用域，慎用（不会自动取消）
作用域确保协程不会泄漏，是结构化并发的核心

### 2. 挂起函数（suspend）
suspend` 关键字标记可挂起的函数
挂起函数只能在协程或其他挂起函数中调用
挂起不会阻塞线程，而是释放线程去做其他事

### 1.协程中网络请求崩溃
原因：在 `Dispatchers.Main` 中直接执行网络请求
解决：用 `withContext(Dispatchers.IO)` 包裹网络操作

### 2.取消协程后仍在执行
原因：协程内部没有检查取消状态
解决：使用 `ensureActive()` 或在循环中检查 `isActive`
OkHttp 的 `execute()` 本身支持中断，取消时会抛出异常

## 关键代码片段

```kotlin
// ViewModel 中使用协程下载
class DownloadViewModel(application: Application) : AndroidViewModel(application) {
    private var downloadJob: Job? = null

    fun startDownload() {
        downloadJob = viewModelScope.launch {
            for ((index, url) in imageUrls.withIndex()) {
                // 切到 IO 线程下载
                val success = withContext(Dispatchers.IO) {
                    downloadImage(url, file)
                }
                // 回到主线程更新进度
                _state.value = _state.value?.copy(progress = index + 1)
            }
        }
    }

    fun cancelDownload() {
        downloadJob?.cancel()  // 取消协程
    }
}
```
