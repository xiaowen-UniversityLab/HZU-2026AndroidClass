### 1. ViewBinding
- ViewBinding 是 Android 官方推荐的视图绑定方案，替代 `findViewById`
- 在 `build.gradle.kts` 中启用：`viewBinding { enable = true }`
- 系统会为每个 XML 布局自动生成一个 Binding 类（如 `ActivityMainBinding`）
- 使用方式：`binding = ActivityMainBinding.inflate(getLayoutInflater())`，然后 `setContentView(binding.getRoot())`

### 2. Retrofit2
- Retrofit 是一个类型安全的 HTTP 客户端，底层基于 OkHttp
- 核心三步：定义接口 → 创建 Retrofit 实例 → 调用接口方法
- `@GET` 注解标记请求方法，`@Query` 注解传递查询参数
- 异步请求使用 `call.enqueue(new Callback<T>())`

### 3. Gson 转换器
- `converter-gson` 自动将 JSON 响应转为 Java 对象
- 需要定义与 JSON 结构对应的 Bean 类（字段名需与 JSON key 一致）

### 坑1：RecyclerView 不显示数据
- 原因：忘记设置 `LayoutManager`
- 解决：`binding.rvNews.setLayoutManager(new LinearLayoutManager(this))`

### 坑2：网络请求在主线程崩溃
- 原因：Android 不允许在主线程执行网络操作
- 解决：Retrofit 的 `enqueue()` 方法自动在子线程执行请求，回调在主线程
```java
// Retrofit 初始化
Retrofit retrofit = new Retrofit.Builder()
        .baseUrl("http://v.juhe.cn/")
        .addConverterFactory(GsonConverterFactory.create())
        .build();
NewsApi newsApi = retrofit.create(NewsApi.class);

// 发起异步请求
newsApi.getTopNews("top", API_KEY).enqueue(new Callback<News>() {
    @Override
    public void onResponse(Call<News> call, Response<News> response) {
        // 更新 UI
    }
    @Override
    public void onFailure(Call<News> call, Throwable t) {
        // 错误处理
    }
});
```
