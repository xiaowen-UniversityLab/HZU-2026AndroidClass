 1.不用getExternalFilesDir(null)，改为媒体数据库写入
  ContentValues cv = new ContentValues();
        cv.put(MediaStore.MediaColumns.DISPLAY_NAME, System.currentTimeMillis() + ".jpg");
        cv.put(MediaStore.MediaColumns.MIME_TYPE, "image/jpeg");
        cv.put(MediaStore.Images.Media.RELATIVE_PATH, "Pictures/CameraX-Lab");
        ImageCapture.OutputFileOptions options = new ImageCapture.OutputFileOptions.Builder(
         getContentResolver(), MediaStore.Images.Media.EXTERNAL_CONTENT_URI, cv).build();
         从而使得照片可以直接在相册的CameraX-Lab查看

2.传感器触发“疯狂连拍卡死”、
   传感器的回调 onSensorChanged 触发频率太高了，所以引入 isCoolingDown 开关变量。一旦触发，立刻置为 true 锁死，
   并通过 handler/postDelayed 延迟，从而防止连拍。

3.运行时一直闪退
   应该是还没拿到用户的动态权限“许可证”， startCamera() 就强行初始化相机问题。
   应该要先执行 ActivityCompat.requestPermissions 去要相机权限（Manifest.permission.CAMERA），并在验证权限后再驱动相机，这样就不会闪退了。
