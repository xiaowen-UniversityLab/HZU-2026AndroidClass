### 1. ORM 映射思想
- ORM（Object-Relational Mapping）将数据库表映射为 Java 对象
- Room 是 Android 官方的 ORM 框架，基于 SQLite，编译时检查 SQL 语句
- 三大核心组件：Entity（表）、DAO（数据访问对象）、Database（数据库）

### 2. Entity 定义
- 使用 `@Entity` 注解标记类为数据库表
- `@PrimaryKey(autoGenerate = true)` 自动生成主键
- 类的字段对应表的列

```java
@Entity(tableName = "favorites")
public class FavoriteArticle {
    @PrimaryKey(autoGenerate = true)
    public int id;
    public String title;
    public String author;
}
```

### 3. DAO 接口
- 使用 `@Dao` 注解标记接口
- `@Insert`、`@Delete`、`@Query` 注解定义数据库操作
- 返回 `LiveData<List<T>>` 可实现数据自动刷新

```java
@Dao
public interface FavoriteDao {
    @Insert
    void insert(FavoriteArticle article);

    @Query("SELECT * FROM favorites ORDER BY timestamp DESC")
    LiveData<List<FavoriteArticle>> getAll();
}
```
### 坑1：主线程操作数据库崩溃
- 原因：Room 默认不允许在主线程执行数据库操作
- 解决：使用 `Executors.newSingleThreadExecutor().execute()` 在子线程操作
