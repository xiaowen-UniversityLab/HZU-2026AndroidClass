1.非空类型（不可为null）      var name: String = "小明"

2. 可空类型（可以为 null）    var name: String? = null


2.1 安全调用符用法：对象？. 方法   name?.length
如果 name 不是 null → 正常返回 length
如果 name 是 null → 直接返回 null，不崩溃

2.2为空时给个默认值：  对象?.属性 ?: 默认值    val len = name?.length ?: 0

2.3非空断言，保证一定不为空  name!!.length

3.扩展函数
fun 原有类名.新方法名(): 返回值 {
    // 方法内容
}

如：
fun String.isBlankOrEmpty(): Boolean {
    return this.isBlank() || this.isEmpty()
}
"hello".isBlankOrEmpty()  // false


4.委托属性
格式var/val 属性名 by 委托对象，懒加载lazy只能用val,不用不加载，第一次访问才加载,只加载一次，后面直接复用
可观察属性用by Delegates.observable(... ){...}，变量值一变，立刻自动提醒，监听数值变化

4.1懒加载委托：by lazy { ... }，第一次用的时候才创建赋值

4.2可观察属性：
var 变量 by Delegates.observable(初始值){
    属性名,旧值,新值 ->
    // 值改变后要做的事
}

如：import kotlin.properties.Delegates
    var obvalue: Int by Delegates.observable(0) { _, oldValue, newValue ->
        println("值从 $oldValue 变成了 $newValue")
    }

    obvalue = 10 // 打印：值从 0 变成了 10
    obvalue = 20 // 打印：值从 10 变成了 20
